## SEQUENCE GATES (NON-NEGOTIABLE — NEVER BYPASSED FOR SPEED)

These gates MUST remain sequential — never parallelized or skipped — regardless of time compression:

GATE 1 — CHALLENGE (Red Team Review Before Production):
Stream B requires red team review complete before PRODUCE continues. No content produced without red team recommendation (PUBLISH / REWORK / ABANDON enforced). Benchmark: < 1h.

GATE 2 — VERIFY (Quality Engine + Governance Before Distribution):
Stream B requires quality scores verified (OMEGA >= 0.60 for PUBLISH; >= 0.95 + R <= 0.05 for ULTRA PLATINUM) + anti-slop verification + analytics hooks verified + governance authorization confirmed before DISTRIBUTE activates. No bypass permitted.

GATE 3 — SCALE AUTHORIZATION (Evidence + Human Gate Before Resource Reallocation):
Stream D requires evidence-based proposal (analytics events + memory updates + compound mechanism verification) + red team complete + governance authorization (OMEGA-M4) + 24h rolling metrics verified + separate announcement gate before any resource reallocation. No automatic scale.

GATE 4 — RECONFIGURE (Governance Approval Before Structural Change):
Stream D requires governance authorization + rollback mechanism verified + memory sync complete + benchmark preservation verified before any structural workflow change integrates. No unauthorized modification.

GATE 5 — PUBLIC ANNOUNCEMENT (Separate Gate After Scale Authorization):
Even after full authorization, public announcement requires separate confirmation. Prevents premature commitment before sustained compound velocity verified.

## NON-NEGOTIABLE PRESERVATION RULES (1-DAY PROTOCOL — NEVER BYPASSED FOR SPEED)

1. **No Context Packet Pollution:** All packets must maintain pollution ≤ 0.3, include FAILURE memory pin, and reference strategic thesis. Violation = automatic stop (not warning).
2. **No AI-Slop Publication:** Every content output must pass anti-slop constitution (intention + information + emotion + identity + transformation). Synthetic/manipulative/generic elements trigger automatic ABANDON or REWORK.
3. **No Clone Integration:** Every competitor-derived insight passes anti-cloning verification (identity claim + format difference + depth difference + emotional difference + evidence difference + strategic alignment + memory new pattern). Cloned content blocked at integration level.
4. **No Scale Without Evidence:** Scale authorization requires structured proposal (evidence + test plan + rollback + approval) + full red team review + governance authorization + 24h rolling metrics verification + separate announcement gate. No automatic resource reallocation permitted.
5. **No Governance Bypass:** Governance Guardian (OMEGA-M4) monitors continuously; any unauthorized change (agent registry modification, strategic thesis change, memory schema change, governance rule change) triggers immediate block + violation log + rollback + new guardrail proposal.
6. **No Failure Memory Deletion:** FAILURE memory is permanent. Every error generates structured entry (Failure → Cause → Fix → Test → New Guardrail). Deletion attempts blocked by database constraint.
7. **No Output Without Memory Update:** Every agent execution, content publication, analytics event, red team review, quality verification, scale proposal, evolution integration writes to at least one memory bank with rollback reference. Empty memory updates blocked.
8. **No Quality Bypass:** Quality engine (5-score framework) applied at every major output. Scores below thresholds trigger enforced actions (REWORK at 0.3-0.6, ABANDON at < 0.3, PUBLISH at > 0.6, SCALE_FAST at > 0.8 + R < 0.2, ULTRA PLATINUM at >= 0.95 + R <= 0.05 + all dimensions verified).
9. **No Strategic Drift:** Every context packet references strategic thesis (≤ 200 chars, aligned with current thesis from STRATEGIC MEMORY). Thesis changes require governance authorization + strategic shift proposal + memory updates.
10. **No Compound Mechanism Degradation:** Every meta-action verifies compound formula (all 9 multipliers present + connected + active) + scope preservation (34/34 files verified) + benchmark preservation (all targets met) + institutional ownership mechanism verified. Degradation triggers meta-evolution proposal (not automatic redesign — proposal requires approval).
