# Version 220 cognitive shift: from agent activity to strategic outcomes

**Status:** Accepted direction · **Architecture generation:** 220 · **Date:** 2026-08-22

“Billion-fold” is treated as an ambition for compounded effective leverage, not a fabricated model
benchmark. Version 220 changes the unit of optimization:

```text
Before: prompt → agents → artifact
After: outcome contract → option portfolio → bounded action → observation → recalibration
```

The system no longer considers a polished plan or completed run to be success. Success is measurable
movement from an explicit baseline toward a target, within authority, capital, time, trust, and risk
budgets.

## Four simultaneous operating scales

1. **30 days — traction:** resolve the most valuable uncertainty and produce measurable movement.
2. **12 months — compounding:** build distribution, reusable capabilities, evidence, and economics.
3. **2026–2030 — portfolio:** allocate capital and learning across ventures while preserving option
   value, governance, and model/provider portability.
4. **Continuous control — reality:** observations update forecasts, allocations, and autonomy.

## Cognitive topology

- **Outcome governor:** owns target, metric, constraints, and stop conditions.
- **Profound diagnostician:** identifies expectation/reality mismatch and causal bottleneck.
- **Epistemic controller:** separates observations, sources, assumptions, forecasts, and unknowns.
- **Scenario council:** builds base, upside, downside, adversarial, and regime-change futures.
- **Option architect:** creates reversible bets with information value and kill criteria.
- **Portfolio allocator:** ranks bets by impact, confidence, cost, reversibility, and strategic fit.
- **Execution commander:** converts authorized bets into dependency-aware campaigns.
- **Observer:** ingests real metric evidence and detects trajectory variance.
- **Recalibrator:** continue, amplify, adapt, pivot, pause, or stop based on evidence.
- **Constitutional auditor:** enforces authority, identity, spend, policy, and rollback invariants.

## Control equation

The system optimizes a vector, not one vanity score:

`strategic utility = outcome progress × evidence quality × option value × trust × reuse`

subject to hard constraints on safety, authority, spend, time, and irreversible harm. Any hard-constraint
violation collapses authorization regardless of predicted utility.
