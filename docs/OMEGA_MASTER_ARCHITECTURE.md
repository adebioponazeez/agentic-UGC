## 4. AGENT CONTRACT MODEL

Every agent has:
- `ROLE`: Identity and mandate
- `TASK`: Current bounded objective
- `AVAILABLE_TOOLS`: Explicit tool registry reference
- `RELEVANT_KNOWLEDGE`: Memory bank pointers (vector + graph + episodic)
- `OUTPUT_CONTRACT`: Schema and validation rules for output
- `FAILURE_CONDITIONS`: Explicit kill conditions and rollback triggers

Every agent interaction carries:
- `CONTEXT_PACKET`: Structured payload (see §6)
- `RUNTIME_STATE`: Current production state machine phase
- `MEMORY_PINS`: References to 6 memory banks

## 5. PRODUCTION STATE MACHINE

```
OBSERVE → CAPTURE → CLASSIFY → CONNECT → RESEARCH → SYNTHESIZE
→ HYPOTHESIZE → CHALLENGE (RED TEAM) → PRIORITIZE → DESIGN → SIMULATE
→ PRODUCE → VERIFY (QA) → PACKAGE → DISTRIBUTE → MEASURE → DIAGNOSE
→ LEARN → STORE (MEMORY) → REINVEST → RECONFIGURE → SCALE / ABANDON
```

States are persistent, observable, and recoverable. No workflow can skip `CHALLENGE`, `VERIFY`, or `LEARN`.

## 8. QUALITY ENGINE (OMEGA SCORE)

Every major output receives 5 independent scores (0–1):

```
C (Creative)  — Is it interesting and authored?
T (Truth)     — Is it accurate and sourced?
P (Production) — Can it actually be produced with available resources?
B (Business)  — Does it create economic value?
R (Risk)      — Could it create unacceptable exposure?

OMEGA SCORE = C × T × P × B × (1 - R)
```

Thresholds:
- < 0.3: ABANDON
- 0.3–0.6: REWORK
- > 0.6: PUBLISH (with human gate)
- > 0.8 + R < 0.2: SCALE FAST

## 9. RED-TEAM COUNCIL (NON-NEGOTIABLE GATE)

Before any major publication:

1. Creative Critic — "Is this boring?"
2. Audience Critic — "Why would anyone care?"
3. Fact Critic — "What is unsupported?"
4. Cinematic Critic — "What looks synthetic or amateur?"
5. Retention Critic — "Where does attention collapse?"
6. Business Critic — "Is there economic value?"
7. Policy Critic — "Could this create platform problems?"
8. Rights Critic — "Do we actually have the rights?"
9. Brand Critic — "Does this damage trust?"
10. Strategic Critic — "Does this move the larger system forward?"

Output: `PUBLISH / REWORK / ABANDON` with structured reasoning.

## 15. GOVERNANCE & NON-NEGOTIABLES

- No AI slop. Every output must have `INTENTION`, `INFORMATION`, `EMOTION`, `IDENTITY`, `TRANSFORMATION`.
- Human-in-the-loop required for: governance changes, major publication, self-modification, budget allocation.
- Red team must approve before scale.
- Failure memory is permanent.
- Context packets must never exceed 10KB uncompressed (anti-pollution rule).
- Every agent must declare its `FAILURE_CONDITIONS` before execution.
